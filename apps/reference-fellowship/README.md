# Reference Fellowship Server

This directory will contain Comb's generic, self-hostable reference server and distribution surface. It is the public implementation used by the conformance suite and must remain useful without private Fellowship infrastructure.

Fellowship is one complete participant in the Comb federation. Other products may implement Issuer and Consumer roles directly and must not need a Fellowship account, deployment, or private API.
